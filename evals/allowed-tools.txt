# The tools that an agent may use in a run of evals/run.sh without asking,
# one permission rule of Claude Code per line. Both arms get the same list;
# a command outside it is refused, and the record counts the refusals.
# Editing files is allowed by the permission mode of the run.
#
# What a developer does in a checkout: read, build, test, and commit. Nothing
# that leaves the checkout: no push, no network tool, no Docker.

# The scope of a check, as AGENTS.md and the Stop hook write it.
Bash(CHECK_SCOPE=changed make *)
Bash(CHECK_FILES=* make *)
