# Reservation の用語集

区切られた文脈 Reservation（予約）のドメインモデルが使う、業務の言葉をまとめる。
各行は、パッケージ `backend/internal/reservation/internal/domain` が公開する型と、その型が表す業務の用語と、用語の意味を示す。

| 識別子 | 用語 | 意味 |
|---|---|---|
| `Reservation` | 予約 | 主催者が、ある時間帯に、ある参加人数で会議室を押さえたもの。確定しているか、取り消されているかのどちらかである。 |
| `ReservationID` | 予約 ID | 予約を見分ける値。会議室を予約したときに作る、バージョン 7 の UUID である。 |
| `RoomID` | 会議室 ID | 会議室を見分ける値。会議室の ID は文脈 Facility が付ける。 |
| `Room` | 会議室 | 予約に必要な範囲で見た会議室。定員、利用時間、タイムゾーンからなる。 |
| `OpeningHours` | 利用時間 | 会議室を使える、毎日の時刻の範囲。会議室のタイムゾーンで読む。 |
| `TimeOfDay` | 時刻 | 24 時間制の時刻。09:00 など。 |
| `Period` | 時間帯 | 予約が会議室を押さえる時間。始まりを含み、終わりを含まないので、ある予約が終わる時刻に次の予約を始められる。 |
| `Status` | 状態 | 予約が会議室を押さえているかどうか。確定か取り消しのどちらかである。 |
| `Event` | ドメインイベント | 予約に起きたことのうち、業務のほかの部分が応じうるもの。 |
| `ReservationConfirmed` | 予約の確定 | 予約が、その時間帯と参加人数で会議室を押さえたこと。会議室を予約したときと、予約を変更したときに起きる。 |
| `ReservationCancelled` | 予約の取り消し | 予約が取り消され、その時間帯の会議室が空いたこと。 |
| `Kind` | 業務エラーの種類 | リクエストが、予約のどの決まりに反するか。 |
| `Error` | 業務エラー | 予約の決まりがリクエストを拒むこと。 |
