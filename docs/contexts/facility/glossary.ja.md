# Facility の用語集

区切られた文脈 Facility で使う言葉と、コードでそれを表す識別子の一覧である。
Facility にはドメイン層がない（TPL-0003）ので、識別子はその `app` パッケージ（`backend/internal/facility/internal/app`）のものである。
このパッケージのエクスポートされた型に行がないとき、または、このパッケージがエクスポートしていないものを行が挙げているとき、`make check` は失敗する（`lint-arch`）。

| 識別子 | 用語 | 意味 |
|---|---|---|
| `Room` | 会議室 | 人が予約できる会議室。Facility が登録し、ほかの文脈は Facility の API を通して読む。 |
| `Room.Name` | 名前 | 人が会議室を呼ぶときの名前。2つの会議室が同じ名前を持つことはない。 |
| `Room.Capacity` | 定員 | 会議室に入れる人数の上限。1 から 1000 までである。 |
| `Room.OpenFrom` | 開く時刻 | 会議室を使い始められる時刻。 |
| `Room.OpenUntil` | 閉まる時刻 | 会議室を使える終わりの時刻。開く時刻より遅いので、日付をまたいで開いている会議室はない。 |
| `Room.TimeZone` | タイムゾーン | 会議室の開く時刻と閉まる時刻を読むときの、IANA のタイムゾーン（`Asia/Tokyo` など）。 |
| `TimeOfDay` | 時刻 | 24 時間制の時と分で表す、日付を持たない時刻。 |
| `Rooms` | 会議室のユースケース | 会議室についてのユースケースをまとめたもの。会議室を登録する、1つの会議室を取得する、会議室の一覧を返す、の3つがある。 |
| `Rooms.RegisterRoom` | 会議室を登録する | 名前、定員、開く時刻と閉まる時刻、タイムゾーンを決めて、会議室を加える。 |
| `RegisterRoomInput` | 会議室の登録内容 | 会議室を登録するのに要るもの。 |
| `Error` | 業務エラー | Facility が理解したが、Facility の規則が拒んだリクエストのエラー。 |
| `Kind` | 業務エラーの種類 | リクエストを拒んだ規則。API は種類ごとに別の problem を返す。 |
