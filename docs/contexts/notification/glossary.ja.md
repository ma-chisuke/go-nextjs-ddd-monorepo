# Notification の用語集

区切られた文脈 Notification で使う言葉と、コードでそれを表す識別子の一覧である。
Notification にはドメイン層がない（TPL-0003）ので、識別子はその `app` パッケージ（`backend/internal/notification/internal/app`）のものである。
このパッケージのエクスポートされた型に行がないとき、または、このパッケージがエクスポートしていないものを行が挙げているとき、`make check` は失敗する（`lint-arch`）。

| 識別子 | 用語 | 意味 |
|---|---|---|
| `Notifier` | 通知のユースケース | Notification のユースケース。処理する Reservation のイベントを、1つにつき1通の主催者宛てのメールにする。同じイベントが何回配信されても、メールは1通である。 |
| `Notifier.HandleEvent` | イベントを処理する | イベントが求めるメールを送り、それを記録する。そのイベントのメールを前に送っていれば、何も送らない。Notification が処理しない種類のイベントは無視する。 |
| `Message` | メール | 1人に宛てた、プレーンテキストのメッセージ。 |
| `Message.To` | 宛先 | メールを届けるメールアドレス。予約の主催者のアドレスである。 |
| `Message.Subject` | 件名 | メールが何についてのものかを示す1行。予約の確定とその開始時刻などを書く。 |
| `Message.Body` | 本文 | メールの文面。予約に何が起きたか、予約の id、会議室の id、UTC で書いた時間帯を書く。 |
| `Mailer` | メーラー | メールをメールサーバーに渡すもの。手元の環境では、SMTP で Mailpit に送る。 |
| `Mailer.Send` | メールを送る | メールをメールサーバーに渡す。サーバーが受け取ったときに限り、メールは送ったことになる。 |
