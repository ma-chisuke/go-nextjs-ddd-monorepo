# 読み取ったあとにリソースが変わった

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 412 とともに返す。

## 意味

リクエストの `If-Match` ヘッダーが挙げるバージョンは、もうリソースの現在のバージョンではない。クライアントが読み取ったあとに、誰かがリソースを変えた。

## 対処

リソースを読み直し、変更がまだ妥当かを確かめる。そのうえで、新しい `ETag` を `If-Match` に入れてリクエストを送り直す。
