# リクエストを読み取れない

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 400 とともに返す。

## 意味

サービスがリクエストを読み取れない。本文の JSON が壊れているか、パラメーターをその型に変換できない。

## 対処

本文を正しい JSON にし、パラメーターを API の文書が示す形で送る。読み取れなかった箇所は `detail` に出る。
