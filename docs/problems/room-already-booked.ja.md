# その時間帯の会議室は予約済みである

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 409 とともに返す。

## 意味

同じ会議室の確定した別の予約が、時間帯と重なっている。接しているだけの 2 つの時間帯は重ならないので、ある予約が終わる時刻に次の予約を始められる。

## 対処

その日の会議室の予約を一覧して、空いている時間帯か、別の会議室を選ぶ。
