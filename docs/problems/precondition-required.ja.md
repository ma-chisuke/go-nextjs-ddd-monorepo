# リクエストに If-Match ヘッダーが要る

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 428 とともに返す。

## 意味

この操作はリソースを変えるが、クライアントがリソースのどのバージョンを見たのかを、リクエストが示していない。示さないと、あるクライアントが、別のクライアントの変更を知らないまま上書きしうる。

## 対処

リソースを読み取り、応答の `ETag` ヘッダーの値を、リクエストの `If-Match` ヘッダーに入れて送る。
