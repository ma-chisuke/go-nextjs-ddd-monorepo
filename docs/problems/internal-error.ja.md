# サービスが失敗した

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 500 とともに返す。

## 意味

サービス自身の不具合で、リクエストを処理できなかった。原因は応答には出さず、サービスのログに残す。

## 対処

時間をおいて、もう一度試す。それでも続くときは、リクエストの時刻を添えて、サービスの運用者に知らせる。
