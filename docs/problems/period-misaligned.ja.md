# 時間帯の始まりと終わりが 15 分単位でない

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 422 とともに返す。

## 意味

予約は 15 分刻みの時刻に従う。時間帯は毎時 0 分、15 分、30 分、45 分のいずれかに始まって終わり、秒を含まない。たとえば 10:00 から 11:15 までである。

## 対処

時間帯の始まりと終わりを 15 分単位にそろえて、リクエストを送り直す。
