# 時間帯の一部が、会議室の利用時間から外れている

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 422 とともに返す。

## 意味

会議室を予約できるのは、利用時間（会議室のタイムゾーンで読んだ `openFrom` から `openUntil` まで）だけである。会議室は開いた日のうちに閉まるので、会議室のタイムゾーンで午前 0 時をまたぐ時間帯は、利用時間に収まらない。

## 対処

Facility API から会議室の利用時間とタイムゾーンを読み、その中に収まる時間帯を選ぶ。
