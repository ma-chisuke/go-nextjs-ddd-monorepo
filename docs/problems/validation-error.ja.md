# リクエストの内容が正しくない

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 422 とともに返す。

## 意味

サービスはリクエストを読み取れたが、その一部が API の文書の決まりに反している。必須のプロパティがない、値が範囲の外にある、文字列が決まった形式でない、などである。

## 対処

`errors` に並んだ箇所を直す。各項目には、箇所を指す `pointer`（本文への JSON Pointer か、パラメーターの名前）と、どの決まりに反するかを示す `detail` がある。
