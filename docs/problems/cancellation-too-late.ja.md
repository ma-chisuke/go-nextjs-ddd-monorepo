# 予約を取り消せる期限を過ぎている

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 422 とともに返す。

## 意味

予約を取り消せるのは、開始の 30 分前までである。リクエストはそれより後に届いたので、予約は確定したままである。

## 対処

この予約は、API ではもう取り消せない。次からは期限より前に取り消す。
