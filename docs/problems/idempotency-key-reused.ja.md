# 冪等キーが別のリクエストで届いた

API は、RFC 9457 の形式のこの problem を、HTTP のステータスコード 422 とともに返す。

## 意味

リクエストの `Idempotency-Key` が、以前に別の本文とともに届いている。1 つのキーは 1 件の予約を表す。同じキーで本文も同じなら最初のリクエストの予約が返り、同じキーで本文が違えば拒否される。

## 対処

予約ごとに新しいキー（ランダムな UUID など）を選ぶ。同じキーを送り直すのは、タイムアウトのあとなどに同じリクエストを繰り返すときだけにする。
